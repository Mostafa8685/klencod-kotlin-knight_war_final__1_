# حرب الفارس: عابر العصور (النسخة المحسّنة)

Android / Kotlin (Canvas + SurfaceView). الـ APK بيتبني من GitHub Actions زي الأول (`.github/workflows/build-apk.yml`).

## اللي اتغيّر
- عوالم Tilemap حقيقية لكل عصر (تصادم مع الحيطان والمية والأشجار، بوابة بتفصل الزعيم، كلها متصلة ببعض).
- حفظ تلقائي + متابعة + إعادة المحاولة من آخر نقطة، وإصلاح التجمّد بعد الخروج والرجوع.
- أصوات ومؤثرات وموسيقى لكل عصر.
- واجهة جديدة: HUD بأيقونات، ميني ماب، أزرار بتتناسب مع الشاشة وفيها cooldown، جويستيك عائم.
- متجر وصناعة جداد: تبويبات، سكرول، تأكيد قبل الشراء، تكلفة بالأيقونات.
- قتال: اتجاه الضربة، ضربة واحدة لكل swing، كريتيكال، ارتداد، قنبلة بانفجار حقيقي، أعداء بنظام تحذير قبل الضرب، زعماء بمراحل.
- أخطاء متصلحة: الدروع، نصل الأبعاد، حامل المفتاح، الإنجليزي/العربي في الحوار، تسريب الـ Paint في كل فريم.
- قصة جديدة (حجر كرونو) وحوارات لكل عصر.
